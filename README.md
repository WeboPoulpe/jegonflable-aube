# 🎪 Jegonflable Aube — Stage WEBOMAX

Site web de location de jeux gonflables — projet de stage de 4 semaines.

---

## 🎯 Ta mission

Bienvenue stagiaire dans le projet **JEGONFLABLE** !

Ce site de location de jeux gonflables a été préparé à 80% par Maxime de **WEBOMAX**. Il contient volontairement **40 bugs et trous** que tu dois trouver et corriger en 4 semaines.

Avant d'attaquer la chasse aux 40 bugs, tu dois passer par un **onboarding interactif en 9 étapes** :
- 🕵️ **5 énigmes code** (1h au total) pour t'apprendre à explorer un projet
- 🛠️ **4 étapes métier longues** (3-4 jours) pour brancher la base de données, Git/GitHub, Vercel et l'envoi d'emails

À chaque étape, tu débloques un **trophée** avec confettis. Les meilleurs sont **légendaires** 👑.

---

## 🚀 Démarrage rapide

```bash
# 1. Installer les dépendances
npm install

# 2. Copier .env.example vers .env.local
# (puis remplir les variables — voir étape 6 de l'onboarding)
cp .env.example .env.local

# 3. Lancer le serveur dev
npm run dev

# 4. Ouvrir http://localhost:3000/onboarding pour commencer
```
